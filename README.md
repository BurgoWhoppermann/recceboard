# Recce Board — website

The pages behind <https://burgowhoppermann.github.io/recceboard>: the overview,
the guide, the support page and the privacy policy. Built by GitHub Pages from
`docs/` on `main`.

These URLs are the ones the App Store listing and the app itself point at, so
the repository name, the `docs/` path and the file names are load-bearing —
changing any of them breaks a link somebody has already been given.

The app's source is not here.
